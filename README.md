# Bar Timer（デスクトップ版）

バー型の目盛りで残り時間がひと目で分かるタイマー。Windows デスクトップアプリ（Tauri 2）と、スマホのホーム画面から使える PWA 版。

KING JIM のビジュアルバータイマー VBT10 を参考に挙動を再現した個人製作の非公式アプリで、同社とは無関係です。

## 再現している実機機能

| 機能 | 内容 |
|---|---|
| 目盛り 20 本 | カウントダウン: 設定時間÷20 ごとに 1 本消える（60分なら 3分/本）。カウントアップ: 約 5 分で 1 本増える |
| モード1 通常計測 | カウントダウン最大 99分50秒 / 00:00 のままスタートでカウントアップ（最大 99分59秒） |
| モード2 リピート計測 | 作業 → 休憩 → 作業 … 最後は作業で終わる。作業最大 99 回・休憩最大 98 回 |
| 設定手順（モード2） | 作業時間 → 決定 → 休憩時間（コップマーク点灯）→ 決定 → リピート数 → 決定で開始 |
| アラーム | 通常計測 約10秒 / リピート切替時 約3秒 / リピート完了時 約10秒。どのボタンでも停止 |
| 消音スイッチ | 右側面スイッチ。消音中は液晶に消音アイコン |
| 時計アイコン | リピート計測モード中に点灯 |
| 一時停止 | 計測中にスタート/ストップで停止・再開（数字が点滅） |
| 計測中の時間追加 | カウントダウン中に 10分/1分/10秒 で延長可（目盛り比率は保持） |
| リセット | 実機は「1分＋10秒 同時押し」。本アプリは「リセット」ボタン / R キー |

目盛りの色は上位機 VBT20 プラスと同じ 4 色（左から 赤・橙・緑・青 各 5 本。右端から消えて最後に赤が残る）。

デスクトップ向けの追加: 常に手前表示、キーボード操作、設定（モード・設定時間・消音）の自動保存、
計測中はウィンドウタイトルに残り時間を表示、ボタン類を隠して液晶だけにするコンパクト表示
（H キー / 本体ホバーで出る「▲ ボタンを隠す」/ 液晶ダブルクリック）。
ウィンドウは最小化できない（最小化ボタンなし。Win+D やタスクバークリックで隠れても 0.3 秒以内に復元）。移動は可。

## キー操作

| キー | 動作 |
|---|---|
| Space / Enter | スタート／ストップ・決定 |
| 1 / 2 / 3 | +10分 / +1分 / +10秒 |
| M | モード切替 |
| N | リピート数 |
| R | リセット |
| S | 消音切替 |
| T | 常に手前 |
| H | ボタン類を隠す / 表示（コンパクト表示） |

## スマホで使う（PWA 版）

`src/` はそのままブラウザでも動くので、GitHub Pages に置いて iPhone / Android の
ホーム画面に追加して使える（ホーム画面から起動すると全画面・オフライン動作）。

- iPhone: Safari で開く → 共有ボタン → 「ホーム画面に追加」
- Android: Chrome で開く → メニュー → 「ホーム画面に追加」（または「アプリをインストール」）

スマホ向けの違い: 縦向きは縦積みレイアウト（消音は下段の「消音」ボタン）、横向きは PC と同じ見た目。
計測中は画面がスリープしない（Wake Lock）。「常に手前」はブラウザでは効かないので非表示。
ブラウザの制限で、画面を消したり別アプリに切り替えているとアラーム音は鳴らない（戻れば残り時間は正しい）。

公開は `.github/workflows/pages.yml` が `main` への push ごとに `src/` を GitHub Pages へデプロイする。

## ビルド（Windows デスクトップ版）

```powershell
cd C:\Users\yone\dev\visual-bar-timer
$env:PATH = "$env:USERPROFILE\.cargo\bin;C:\msys64\mingw64\bin;$env:PATH"
npm install
node "node_modules\@tauri-apps\cli\tauri.js" build --no-bundle
# → C:\rust-builds\visual-bar-timer\release\visual-bar-timer.exe
```

フロントエンドは `src/`（素の HTML/CSS/JS、バンドラ不要）。Rust 側はウィンドウを開くだけ。
